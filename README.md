# Wayseer Desktop issues

Report a bug in [Wayseer Desktop](https://wayseer.app), or ask for a feature or a module, by
[opening an issue](https://github.com/wayseer-net/desktop-issues/issues/new/choose). The app's
source is private, so this repository holds only its issues; we link each fix here and close the
issue when a release ships it.

- **Check first:** search the [open and closed issues](https://github.com/wayseer-net/desktop-issues/issues?q=is%3Aissue)
  in case someone has reported it already. If they have, add a 👍 or what is different for you.
- **Leave out what's private:** issues are public. Before you paste a screenshot, a config or the
  app's output, remove your hostnames, addresses, credentials and license key.
- **Security problems** go in a [private report](https://github.com/wayseer-net/desktop-issues/security/advisories/new),
  never an issue. See [SECURITY.md](SECURITY.md).
- **No GitHub account?** Write to [hello@wayseer.net](mailto:hello@wayseer.net).

Bugs in the [SDK](https://github.com/wayseer-net/desktop-sdk), the
[module template](https://github.com/wayseer-net/desktop-module-template) or a free module go in
that repository's own issues.
