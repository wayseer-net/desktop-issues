# Reporting a security problem

Please don't open a public issue. Report it privately instead, by either:

- [a private report on GitHub](https://github.com/wayseer-net/desktop-issues/security/advisories/new),
  seen only by you and Wayseer; or
- email to [hello@wayseer.net](mailto:hello@wayseer.net) with "Security" in the subject.

Say which version you used (`wayseer --version`), what you found, and how to reproduce it. We
reply within a week, tell you what we'll do, and credit you in the release notes unless you'd
rather we didn't.

Security problems in a published release of Wayseer Desktop, its signed downloads, license
keys, marketplace modules and the services at wayseer.app are all in scope.
